## 🧩 What this project supports
This repository provides static HTML learning examples. It does not provide hosted services, user accounts, a backend, database support, or guaranteed tutoring.

## 🐛 Reporting a problem
Open a GitHub issue for reproducible exercise bugs or documentation errors. Include the exercise ID, browser and version, operating system, exact reproduction steps, expected result, actual result, and sanitized console errors.

Do not post passwords, tokens, private contact details, or other sensitive information.

## 🧭 Escalation
For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue. For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## ⏱️ Response expectations
The repository is maintained on a best-effort basis. There is no guaranteed response time, support contract, or emergency on-call service.
