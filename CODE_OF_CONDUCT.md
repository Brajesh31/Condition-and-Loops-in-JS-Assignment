# 🤝 Community Code of Conduct

## 🌱 Purpose and commitment
This repository is a learning space for people practicing JavaScript fundamentals. Participants should be able to ask basic questions, make mistakes, and improve without being mocked or excluded.

## ✅ Expected behavior
- Treat learners, reviewers, and maintainers with respect.
- Give feedback about code and ideas, not personal characteristics.
- Explain corrections with examples where possible.
- Be patient with different experience levels and communication styles.
- Respect privacy, licenses, and attribution.
- Keep discussions relevant to JavaScript learning and repository maintenance.

## 🚫 Unacceptable behavior
Harassment, discrimination, threats, personal attacks, doxxing, unwanted sexual attention, deliberate disruption, and publishing private information without permission are prohibited. Repeated bad-faith behavior and knowingly submitting malicious code are also unacceptable.

## 🧭 Maintainer responsibilities
The maintainer will review reports, assess context, and choose a proportionate response. Possible actions include a warning, editing or removal of inappropriate content, temporary participation limits, rejection of a contribution, or permanent exclusion from project spaces.

## 📣 Reporting and investigation
Report conduct concerns privately through the contact method listed on the repository owner's GitHub profile. Include relevant links, dates, and context. Do not publish sensitive details in a public issue. Reports will be handled as confidentially as practical, reviewed fairly, and acted on based on available evidence.

## ⚖️ Scope
This policy applies to repository issues, pull requests, discussions, code reviews, and project-related communication spaces. It applies when a person's project participation is affecting the safety or wellbeing of the community.

## 🔗 Reference
This policy is inspired by common open-source community standards. It is maintained for this repository and is not a substitute for platform rules or applicable law.
