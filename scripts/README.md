# ⚙️ Repository Validation Scripts

| Script | Purpose |
|---|---|
| validate-exercises.py | Check five exercise pages and referenced images |
| validate-docs.py | Check relative Markdown links |
| check-project-structure.py | Check required core files |
| validate-markdown.py | Basic Markdown hygiene |
| security-check.py | Heuristic scan for obvious secrets |

Run scripts from the repository root with Python 3. These checks do not replace browser, security, or accessibility audits.
