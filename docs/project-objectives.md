# 🎯 Project Objectives

## Learning objectives
- Identify true and false conditions.
- Select an appropriate conditional construct.
- Understand ordered branch evaluation.
- Explain `switch` case matching and `break`.
- Trace a `for` loop's three control expressions.
- Explain the pre-test behavior of `while`.
- Explain why `do...while` executes at least once.
- Calculate the output of loop counters and transformed expressions.
- Spot off-by-one errors and non-terminating loops.

## Repository objectives
- Preserve the original assignment pages and learning assets.
- Document actual behavior accurately.
- Make local execution straightforward.
- Provide maintainable contribution and security guidance.
- Add useful validation without imposing a large toolchain.
