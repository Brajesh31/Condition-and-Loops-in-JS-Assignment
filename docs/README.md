## 📌 Reading order
Start with the product overview, then the exercise guide, then the JavaScript concepts reference. Maintainers should also read project structure, testing, security, and contribution guidance.

## 🔍 Accuracy rule
A document describes current implementation only when the corresponding code exists. Future ideas are marked as proposals; unsupported backend, database, API, and compliance claims are excluded.
