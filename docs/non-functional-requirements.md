# 📐 Non-Functional Requirements and Quality Attributes

The repository is a static learning assignment. These are practical expectations for maintaining it, not claims of audited conformance.

| Attribute | Expectation | Verification |
|---|---|---|
| Usability | A learner can open an exercise without a build step | Browser smoke check |
| Clarity | Code and explanations remain beginner-readable | Review |
| Portability | Pages work in current mainstream browsers | Manual browser testing |
| Maintainability | Exercise behavior and docs stay synchronized | PR review |
| Accessibility | Pages use meaningful titles, headings, and image alternatives | Accessibility review |
| Security | No secrets or unnecessary executable dependencies | Source review |
| Reliability | Loops terminate for their documented values | Output and boundary checks |

There is no formal performance SLA, availability target, WCAG certification, or security audit for this repository.
