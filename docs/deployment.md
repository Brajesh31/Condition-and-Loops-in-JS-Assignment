# 🚀 Deployment

## Current deployment model
The repository is a static HTML assignment. No production deployment workflow or live application URL is defined by the exercise source.

## Optional static hosting
The pages can be served by any static file host that preserves the repository's directory structure and relative image paths. No backend runtime is needed.

## Pre-publication checklist
- [ ] Q1-Q5 are present.
- [ ] Relative image paths work after upload.
- [ ] README links point to the correct repository paths.
- [ ] Console output is checked in the target browser.
- [ ] No secrets or private information are included.

Do not describe a host as configured until a real deployment has been created and verified.
