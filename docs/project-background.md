# 📖 Project Background

This repository is organized around an assignment titled **Assignment 19: Conditions and Loops in JavaScript**. It uses isolated examples rather than a combined application so that each control-flow concept can be inspected independently.

The existing files show a progression from conditional statements (Q1), to a grade-selection chain (Q2), to three loop forms (Q3), then numeric range and counting examples (Q4-Q5).

The repository does not include a formal course syllabus, grading rubric, instructor brief, or external deployment specification. This document therefore describes only the context visible in the checked-in assignment.
