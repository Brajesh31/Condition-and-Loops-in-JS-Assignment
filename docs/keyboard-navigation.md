# ⌨️ Keyboard Navigation

The current pages are simple HTML documents and do not provide a custom interactive navigation system.

## Expected baseline
- Browser navigation should remain available through standard keyboard controls.
- Links and controls added in future pages must be reachable and operable by keyboard.
- Focus indicators must remain visible.
- Avoid custom keyboard traps.
- Do not require pointer gestures for essential learning tasks.

## Manual checks
Tab through any links or controls, use Enter or Space as appropriate, and confirm focus order follows the content.
