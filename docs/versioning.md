# 🔖 Versioning

No formal semantic versioning policy is currently enforced. If tagged releases are introduced, use a consistent version format and explain what constitutes a breaking change for the assignment.

Suggested interpretation:
- Patch: documentation corrections or non-breaking exercise fixes.
- Minor: additional exercises or learning content.
- Major: incompatible restructuring or changes to established exercise behavior.

Update changelog and release notes with each published tag.
