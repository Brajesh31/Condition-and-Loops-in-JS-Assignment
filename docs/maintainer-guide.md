# 🧭 Maintainer Guide

## Routine maintenance
- Review issues and pull requests.
- Confirm proposed changes preserve the assignment's learning goals.
- Run the repository validator.
- Open changed pages in a browser.
- Check local asset references and documentation links.
- Keep GitHub Actions and third-party action versions under review.
- Update changelog and roadmap when scope changes.

## Release discipline
Use [the release checklist template](templates/release-checklist.md). A release note must describe only changes that were actually merged.

## Security reports
Follow root [SECURITY.md](../SECURITY.md). Rotate exposed credentials immediately if any are introduced and leaked.

## Repository integrity
Preserve original assignment pages and assets. Keep the documented file tree synchronized with the real tree. Mark unimplemented improvements as planned.
