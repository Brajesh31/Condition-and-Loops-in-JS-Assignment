# 📦 Dependencies and External Resources

## Runtime dependencies
The current exercise pages do not import third-party JavaScript packages. They use browser-provided HTML and JavaScript capabilities.

## Development dependencies
No package manager, test framework, linter, or bundler is currently required. Python 3 is used by the optional structural validator and can also serve the files locally.

## Local image assets
Q1-Q3 reference seven local PNG assets under the assignment's `asset/` directory. Three existing output screenshots are stored under `OutPut/`.

## Dependency policy
- Add a dependency only when it materially improves the learning experience or validation.
- Prefer standard browser APIs for beginner examples.
- Pin and review GitHub Actions used in workflows.
- Document new runtime requirements and update CI commands together.
- Never claim a dependency is installed when no manifest exists.
