# ⚠️ Known Issues and Limitations

The following observations describe the existing assignment and are not necessarily defects.

| Area | Observation | Impact |
|---|---|---|
| Output | Exercises primarily use `console.log` | Learner must open Developer Tools |
| Input | Example values are hard-coded | No interactive input practice |
| Q4 | `num1` and `num2` are declared but unused | May distract from loop explanation |
| Q4 | Logs `i + 1` while counter starts at 5 | Display differs from counter |
| Q5 | Descending loop logs `j - 1` | Output starts at 24 |
| Evidence | Screenshots exist for Q1-Q3 only | Q4/Q5 lack screenshot evidence |
| Testing | No automated JavaScript behavior suite | Manual browser verification needed |

Potential improvements are tracked in [ROADMAP.md](../ROADMAP.md). Do not silently change assignment behavior without explaining the learning impact.
