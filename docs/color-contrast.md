# 🎨 Color Contrast

No formal contrast measurements have been recorded for the existing exercise pages.

## Guidance for future visual changes
- Use text/background combinations that meet WCAG 2.2 AA contrast expectations where applicable.
- Do not use color as the only way to distinguish a correct answer or branch.
- Preserve readable focus indicators.
- Check diagrams and badges as well as body text.
- Test contrast in normal and high-contrast display settings where practical.

Record measured ratios and the tool used in an audit rather than claiming compliance without evidence.
