# 🧑‍💻 Code Standards

## JavaScript examples
- Keep examples focused on one learning objective.
- Use descriptive names for newly introduced variables.
- Prefer strict equality where equality comparison is intended.
- Indent nested blocks consistently.
- Ensure each loop has a clear termination path.
- Explain non-obvious boundaries and output transformations.
- Avoid unnecessary dependencies and advanced syntax that distracts from the lesson.

## HTML
- Use a document title that describes the exercise.
- Keep document language metadata.
- Use semantic headings and meaningful image alternatives.
- Keep relative asset paths correct.
- Ensure instructional content is understandable without color alone.

## Documentation
- Use descriptive headings and useful tables.
- Include emojis where they improve scanning, not as decoration in every sentence.
- Cross-link related guides.
- Distinguish current implementation from proposed improvements.
- Never invent metrics, screenshots, endpoints, test results, or compliance claims.
