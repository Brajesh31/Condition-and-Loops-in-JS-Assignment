# 🔊 Screen Reader Support

No formal screen reader compatibility testing has been recorded for the current pages.

## Guidance
- Use semantic HTML and meaningful heading levels.
- Add useful alt text to instructional images.
- Keep code examples as selectable text.
- Avoid embedding essential explanations only in images.
- If dynamic output is added, provide a text representation and test announcement behavior carefully.

## Evidence
Record screen reader, browser, operating system, page, and observed result when testing. Do not claim support for a screen reader that has not been tested.
