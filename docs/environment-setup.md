# ⚙️ Environment Setup

## Required
- Modern browser with JavaScript enabled.

## Optional tools
- Git for cloning and contributing.
- Python 3 for validation and a local static server.

## Setup
```bash
git clone https://github.com/Brajesh31/Condition-and-Loops-in-JS-Assignment.git
cd Condition-and-Loops-in-JS-Assignment
python scripts/validate-exercises.py
```

There are no environment variables, package installs, database credentials, or secrets to configure.
