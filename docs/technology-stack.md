# 🧰 Technology Stack

| Technology | Current use | Required version |
|---|---|---|
| HTML | Page structure | Browser-supported HTML |
| JavaScript | Inline control-flow examples | Modern browser JavaScript |
| Browser Developer Tools | Displays console output | Current mainstream browser |
| Python | Optional validation script | Python 3 |

No frontend framework, backend runtime, database, package manager, CSS framework, or build tool is part of the current assignment.

## Why the stack is intentionally small
The concepts being taught are language-level control flow. Extra libraries would add setup overhead without helping explain conditions or loops.
