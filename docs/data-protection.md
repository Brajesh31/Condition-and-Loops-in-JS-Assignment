# 🛡️ Data Protection

## Current data handling
The exercise pages use hard-coded teaching values and write messages to the browser Console. They do not ask learners to submit personal data or persist user records.

## Repository collaboration
Issue and pull-request authors may voluntarily include identifying details in their GitHub profiles or reports. Avoid requesting unnecessary personal information and do not publish secrets in issue content.

## Future changes
If interactive input or telemetry is introduced, define purpose, data minimization, retention, deletion, access, and security controls before collecting information.
