# 🤝 Contributor Guide

## Before contributing
Read [CONTRIBUTING.md](../CONTRIBUTING.md), [project structure](project-structure.md), and [the exercise guide](exercises-guide.md).

## Choose the right place
- Q1: conditional statements.
- Q2: grade selection.
- Q3: loop forms.
- Q4: numeric range.
- Q5: ascending and descending counters.
- docs/: learning and maintainer guidance.
- scripts/: real validation utilities.
- .github/: contribution and automation configuration.

## Review expectations
A contribution should be accurate, focused, beginner-friendly, and verifiable. Keep documentation synchronized with code and disclose checks that were not run.

## Security and conduct
Follow root [SECURITY.md](../SECURITY.md) and [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).
