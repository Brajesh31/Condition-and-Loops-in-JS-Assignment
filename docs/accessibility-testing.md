# 🧪 Accessibility Testing

## Manual test plan
| Check | Method | Evidence to record |
|---|---|---|
| Document title | Browser tab and accessibility tree | Title per page |
| Heading structure | Inspect heading outline | Logical hierarchy |
| Image alternatives | Inspect accessibility tree | Alt text and purpose |
| Keyboard | Tab, Enter, Space | Focus order and operability |
| Zoom | Browser zoom to 200% | Content remains usable |
| Contrast | Contrast analyzer | Measured ratio |
| Screen reader | Supported screen reader/browser pair | Spoken labels and order |
