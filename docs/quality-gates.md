# 🚦 Quality Gates

A change is ready for review when applicable checks below are complete.

## Required for exercise changes
- [ ] Original assignment intent is preserved or the behavior change is explained.
- [ ] Structural validator passes.
- [ ] Changed page opens in a browser.
- [ ] Console output matches the documented result.
- [ ] Local image references resolve.
- [ ] Relevant README and docs are updated.
- [ ] No secrets or unrelated generated files are included.

## Required for documentation changes
- [ ] Claims match the source.
- [ ] Internal links resolve.
- [ ] Diagrams describe real behavior.
- [ ] Proposed features are clearly labeled.
- [ ] No fake screenshots, metrics, or test results.

## Status discipline
A checklist is not evidence by itself. Record the actual command and result before marking a check complete.
