# 🌍 Hosting Options

## Static hosting requirement
Any host that serves HTML and local image files can publish this assignment. Keep the assignment directory and its `asset/` and `OutPut/` subdirectories intact.

## Local preview
```bash
python -m http.server 8000
```

## Deployment status
No verified live deployment URL is documented in this repository. Add one to the README only after publishing and testing the pages.
