# ✨ Existing Features

## 🧭 Q1: Conditional statements
Demonstrates `if`, `if...else`, and `switch` using age, temperature, and day values.

## 🏅 Q2: Grade classification
Uses an ordered conditional chain with a hard-coded marks value of 80. The second branch is selected.

## 🔁 Q3: Loop comparison
Demonstrates `for`, `while`, and `do...while`, each producing five numbered messages.

## 🔢 Q4: Numeric range
Runs a counter from 5 through 14 and logs the counter plus one, displaying 6 through 15.

## ↕️ Q5: Ascending and descending output
Displays 1 through 25 in the first loop and 24 down through 1 in the second.

## 📦 Repository assets
The assignment includes seven referenced instructional images and three output screenshots. No live application features, user accounts, API integrations, or persistent data features are implemented.
