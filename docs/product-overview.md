# 🎯 Product Overview

## 📌 What this repository is
A small JavaScript assignment containing five standalone HTML documents. Each page embeds JavaScript and demonstrates a narrow control-flow concept. Learners open a page in a browser and inspect `console.log` output.

## 👥 Audience
Students new to JavaScript, instructors introducing control flow, and contributors improving beginner-level explanations.

## 🧠 Learning outcomes
After working through the assignment, learners should be able to:
1. Explain how a Boolean condition selects a branch.
2. Compare `if` chains with `switch`.
3. Trace initialization, condition checks, body execution, and updates in loops.
4. Predict the output of inclusive and exclusive boundaries.
5. Recognize infinite-loop and off-by-one risks.

## 📦 Scope
Included: Q1-Q5 HTML, embedded JavaScript, seven referenced teaching images, and three existing screenshots. Excluded: server, database, API, accounts, dynamic input forms, application routing, and production deployment.

## 📏 Success criteria
A learner can open each question, find its output in the browser Console, and explain why each branch or iteration ran.
