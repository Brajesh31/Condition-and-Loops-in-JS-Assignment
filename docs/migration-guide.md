# 🔀 Migration Guide

There is no framework migration or database schema migration in the current static assignment.

## Moving or renaming an exercise
- Update README links.
- Update documentation tables and diagrams.
- Check relative image references.
- Verify screenshots and asset paths.
- Run structural validation.
- Open the moved page in a browser.

## Changing exercise behavior
Document old and new behavior, explain the learning reason, update expected output, and add boundary tests where practical.
