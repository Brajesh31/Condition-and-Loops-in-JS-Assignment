# 🏷️ Repository Visual Identity

## Direction
Use a clear educational identity centered on JavaScript control flow. Relevant visual motifs include branching paths, decision diamonds, iteration arrows, and numbered counters.

## Documentation visuals
- Use consistent title and heading styles.
- Prefer diagrams that explain a real concept over decorative artwork.
- Use relevant emojis sparingly in headings.
- Keep SVGs simple, legible, and scalable.
- Use meaningful alt text for all informative images.

## Screenshot integrity
Screenshots must come from the actual exercise pages. Do not create mock UI screenshots or depict nonexistent features as current functionality.
