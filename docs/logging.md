# 🪵 Logging and Console Output

## Current approach
The assignment uses JavaScript `console.log` statements as its output mechanism. Messages are visible in browser Developer Tools, not necessarily in the document body.

## Learner workflow
1. Open the exercise page.
2. Open Developer Tools.
3. Select Console.
4. Reload the page.
5. Read the messages in order.

## Recommendations for future examples
Use concise labels that identify the exercise or loop. Avoid logging secrets or personal information. If a future UI output panel is added, retain accessible text output rather than relying only on color or animation.
