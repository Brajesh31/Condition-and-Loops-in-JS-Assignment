# ❓ Frequently Asked Questions

## Why is the page blank?
The examples primarily use `console.log`. Open Developer Tools and select Console.

## Do I need Node.js?
No. Open the HTML pages directly in a modern browser. Python is optional for the repository validation script or a local static server.

## Why does Q4 display 6 first when the counter starts at 5?
The loop logs `i + 1`, not `i`.

## Why does Q5 descend from 24 instead of 25?
The second loop begins with a counter of 25 but logs `j - 1`.

## Why does do...while run at least once?
It executes its body before checking its condition.

## Is there a backend or database?
No. The current repository contains static HTML and embedded JavaScript only.

## Are the screenshots available for every question?
The repository contains three output screenshots for Q1-Q3. Q4 and Q5 do not currently have screenshot evidence.

## How do I report a bug?
Use GitHub Issues for reproducible non-security bugs. Follow [SECURITY.md](../SECURITY.md) for vulnerability reports.
