# ♿ Accessibility Guidance

This is a set of educational HTML documents, not a certified accessible application. The recommendations below guide improvements; they are not claims of WCAG conformance.

## Core practices
- Use `lang="en"` and descriptive page titles.
- Maintain a logical heading hierarchy.
- Add meaningful alternative text to instructional images.
- Keep text readable at 200% zoom.
- Ensure sufficient contrast and never communicate meaning through color alone.
- Make any future interactive controls keyboard operable.
- Provide text equivalents for important visual instructions.
- Explain how to access Console output without relying on color or visual timing.

## WCAG target
Use WCAG 2.2 AA as an improvement target where applicable. No formal conformance audit has been performed.

## Review checklist
- [ ] Title and language metadata.
- [ ] Heading order.
- [ ] Image alternatives.
- [ ] Keyboard access.
- [ ] Contrast and zoom.
- [ ] Text-based output and instructions.
