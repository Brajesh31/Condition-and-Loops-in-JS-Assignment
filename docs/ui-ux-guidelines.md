# 🎨 UI and Learning Experience Guidelines

The current project uses simple HTML pages and is primarily a code-and-console learning experience. This guide provides standards for future page improvements; it does not claim a formal design system already exists.

## Learning-first presentation
- Put the exercise title and objective near the top.
- Keep code examples focused and readable.
- Explain how to inspect output in the browser Console.
- Separate instructions, code, and expected output.
- Use examples that can be followed manually.

## Responsive behavior
Pages should remain usable on narrow screens. Avoid fixed-width content that forces horizontal scrolling. Use readable line lengths and allow code blocks to scroll horizontally when needed.

## Feedback and output
Do not rely on color alone to indicate success or failure. If an on-page output panel is introduced, make output selectable and accessible to assistive technology.

## Evidence
Capture only genuine browser output from the current implementation. Label each screenshot with the corresponding exercise and browser context where useful.
