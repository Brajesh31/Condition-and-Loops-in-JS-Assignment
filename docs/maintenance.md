# 🧹 Maintenance Guide

## Routine maintenance
- Check that Q1-Q5 remain present.
- Run `python scripts/validate-exercises.py`.
- Open changed pages and inspect Console output.
- Verify local image paths.
- Review internal documentation links.
- Update the changelog for meaningful changes.
- Reassess the roadmap and known issues.

## Dependency maintenance
There are no application package dependencies. Review GitHub Actions and Dependabot configuration when workflows are present.

## Preservation
Do not delete original exercise pages, screenshots, or instructional images as a cleanup shortcut.
