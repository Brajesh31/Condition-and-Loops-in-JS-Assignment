# 📦 Scope and Limitations

## ✅ Included
- Five standalone HTML assignment pages.
- Embedded JavaScript examples for conditions and loops.
- Seven instructional image assets.
- Three existing output screenshots.
- Browser Console-based output.
- Documentation and repository maintenance guidance.

## 🚫 Not present in the current implementation
- Backend or web server application.
- Database, schema, or persistent storage.
- Login, authentication, roles, or authorization.
- API endpoints, webhooks, or integrations.
- Frontend framework, router, or component library.
- Build system, package manager, or dependency lockfile.
- Automated JavaScript unit or end-to-end test suite.
- Live demo or production hosting configuration.

## ⚠️ Learning limitations
- Examples use hard-coded values rather than interactive input.
- Console output requires Developer Tools.
- Q4 declares variables that are not used.
- Q4 and Q5 transform the displayed counter value, which may confuse beginners without explanation.
- Existing screenshots cover Q1-Q3 only.

## 🔭 Potential future work
Add expected-output panels, input-boundary challenges, automated behavior tests, and accessible page structure. These are proposals, not existing features.
