# 🧩 Problem Statement

Beginners often find control flow difficult because the program's output depends on the order of conditions and repeated changes to state. A counter may differ from the value printed, and a loop's stopping condition may include or exclude a boundary.

This assignment addresses those foundational questions through small examples. Q1 and Q2 demonstrate branch selection; Q3 compares loop structures; Q4 and Q5 expose the relationship between counter values, conditions, and displayed output.

The current pages are console-oriented. Learners must know how to open Developer Tools to observe results. An on-page output view is a possible future improvement, not an existing feature.
