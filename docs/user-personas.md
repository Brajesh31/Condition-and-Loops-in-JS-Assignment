# 👤 Learner Personas

Personas below are practical usage profiles for this educational material, not research participants or measured user segments.

## 🌱 First-time JavaScript learner
**Goal:** Understand why a condition or loop produces a particular output.

**Needs:** Short examples, plain-language explanations, expected output, and instructions for opening the browser Console.

**Likely friction:** Confusion about `<` versus `<=`, loop updates, and console visibility.

## 🧑‍🏫 Instructor or mentor
**Goal:** Demonstrate control-flow concepts and give students a small codebase to inspect.

**Needs:** Exercise mapping, reproducible behavior, and clear boundaries between existing examples and suggested extensions.

## 🛠️ Repository contributor
**Goal:** Correct or extend the assignment without breaking original material.

**Needs:** Project structure, contribution workflow, validation script, and accurate documentation.
