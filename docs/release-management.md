# 📦 Release Management

## Current release model
The repository is a small educational assignment and does not currently declare a formal release cadence or packaged binary.

## Release preparation
- Review merged changes.
- Update [CHANGELOG.md](../CHANGELOG.md).
- Run structural validation.
- Open changed pages in a browser.
- Verify documentation and local links.
- Confirm the license and asset attribution.
- Use the [release checklist](templates/release-checklist.md).

## Release notes
Describe added exercises, corrected behavior, documentation changes, and known limitations. Do not claim a test or deployment that was not performed.
