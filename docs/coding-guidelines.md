# ✍️ Coding Guidelines

## Before changing an exercise
1. Read the whole page.
2. Identify the intended concept.
3. Trace the existing output.
4. Decide whether the change corrects a bug or changes the lesson.
5. Update the exercise guide and README if behavior changes.

## Loop safety
For each loop, identify initialization, condition, update, and the value being printed. Check the initial and final iterations. A loop must be able to reach a false condition for its documented inputs.

## Conditional safety
Order overlapping ranges from most restrictive to least restrictive. Test exact threshold values and values immediately above and below each boundary.

## Review
Keep changes small and verify them in a browser. Do not rewrite original exercises merely to match a personal style preference if the learning objective is unchanged.
