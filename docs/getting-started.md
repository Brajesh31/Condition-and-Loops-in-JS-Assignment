# 🚀 Getting Started

## Your first exercise
1. Open the repository's assignment directory.
2. Open `Q1.html` in your browser.
3. Press F12 or use the browser menu to open Developer Tools.
4. Select the Console tab.
5. Reload the page.
6. Read the age, temperature, and weekday messages.
7. Change one value locally and predict the output before reloading.
