# 🛠️ Local Development

## Direct browser workflow
Open the selected HTML page directly. The assignment does not require a local server.

## Optional static server
From the repository root:
```bash
python -m http.server 8000
```
Visit `http://localhost:8000/` and navigate to the assignment directory.

## Editing workflow
1. Edit one exercise.
2. Run the structural validator.
3. Open the changed page in a browser.
4. Check the Console and referenced images.
5. Update the README and relevant docs.
6. Review the diff before committing.

## No package toolchain
There is no npm, pnpm, Yarn, Bun, or frontend build pipeline in the current repository.
