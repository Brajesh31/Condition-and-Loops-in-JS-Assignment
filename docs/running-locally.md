# ▶️ Running Locally

## Recommended: open the page directly
Open any file from the assignment directory:
- `Q1.html`
- `Q2.html`
- `Q3.html`
- `Q4.html`
- `Q5.html`

The pages are independent and do not need a server.

## Optional: Python static server
Run from the repository root:
```bash
python -m http.server 8000
```
Open `http://localhost:8000/`, then browse into the assignment folder. Stop the server with Ctrl+C.

This is a static file server, not an application backend.
