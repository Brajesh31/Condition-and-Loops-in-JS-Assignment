# 🔏 Privacy Overview

## Current behavior
The exercise pages contain hard-coded examples and write output to the local browser Console. They do not implement accounts, telemetry, analytics, cookies, server-side storage, or a data collection endpoint.

## Repository collaboration
GitHub may process profile information and issue or pull-request content under its own service terms. Contributors should avoid posting private data, credentials, or unnecessary personal details.

## Future changes
If the project begins collecting learner input or usage data, document the purpose, legal basis where applicable, data minimization, retention, deletion, access, and security controls before launch.
