# 📖 JavaScript Control-Flow Glossary

| Term | Meaning |
|---|---|
| Condition | Expression evaluated to decide whether code runs |
| Boolean | A value of `true` or `false` |
| Branch | A possible path through conditional code |
| if statement | Executes a block when its condition is truthy |
| else | Fallback branch when earlier conditions fail |
| else if | Additional condition in an ordered branch chain |
| switch | Selects a case matching an expression |
| case | A labeled branch in a switch |
| break | Exits the nearest loop or switch |
| Iteration | One execution of a loop body |
| Initialization | Sets the initial loop state |
| Loop condition | Determines whether another iteration occurs |
| Update | Changes loop state between iterations |
| Counter | Variable commonly used to track loop progress |
| Infinite loop | Loop whose termination condition never becomes false |
| Off-by-one error | Boundary mistake that adds or omits an iteration/value |
| Pre-test loop | Checks its condition before the body |
| Post-test loop | Executes the body before checking its condition |
| Console | Browser developer tool that displays logged output |
