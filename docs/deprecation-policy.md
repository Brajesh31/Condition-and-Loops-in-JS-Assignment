# 🧭 Deprecation Policy

This repository does not currently expose a public API or stable software package. Deprecation mainly applies to exercise pages, examples, and documentation.

Before removing or renaming an exercise:
1. Explain why it is obsolete or incorrect.
2. Check links and references in README and docs.
3. Preserve learning value where possible.
4. Provide a replacement or migration note if students may rely on it.
5. Update changelog and roadmap.
6. Avoid deleting original assets without verifying references.
