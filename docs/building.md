# 🏗️ Building

## Current status
There is no build process. Each exercise is a standalone HTML document that the browser reads directly.

## Why no build command exists
The assignment does not use a bundler, transpiler, CSS processor, module packaging step, or compiled assets. Adding a build pipeline would increase maintenance without a current requirement.

## Optional future tooling
If the project adds automated JavaScript tests, document the runtime and test command. Do not label a workflow as a build unless it actually builds an artifact.
