# ♿ Accessibility Guidelines

## HTML structure
Use semantic headings, lists, paragraphs, and code elements. Avoid using visual styling as a substitute for semantic structure.

## Images
Provide concise alt text for informative diagrams and screenshots. Use empty alt text only when an image is purely decorative and adds no information.

## Code and output
Keep code text selectable. Explain how to open browser Developer Tools. If an on-page output area is introduced, ensure updates can be perceived by assistive technologies without disruptive announcements.

## Responsive layout
Do not force fixed-width page layouts. Ensure code samples can scroll horizontally without hiding surrounding instructions.

## Review
Check keyboard operation, zoom, contrast, headings, and screen reader interpretation manually. Record actual results.
