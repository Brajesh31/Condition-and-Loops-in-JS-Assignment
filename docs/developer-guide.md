# 👩‍💻 Developer Guide

## Understand the project
Read [architecture](architecture.md), [project structure](project-structure.md), and [exercise guide](exercises-guide.md) before editing.

## Make a change
1. Choose the exercise that owns the learning objective.
2. Keep the code understandable to a beginner.
3. Trace expected behavior manually.
4. Run structural validation.
5. Test the changed page in a browser.
6. Update documentation and actual screenshots where necessary.

## Avoid
- Introducing a framework for a five-page static assignment without a clear need.
- Creating fake API, database, login, or deployment documentation.
- Adding passing badges before workflows have run successfully.
- Removing original teaching assets.
