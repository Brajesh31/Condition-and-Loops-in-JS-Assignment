# 📥 Installation

No installation or dependency setup is required to use the existing assignment.

## Clone with Git
```bash
git clone https://github.com/Brajesh31/Condition-and-Loops-in-JS-Assignment.git
cd Condition-and-Loops-in-JS-Assignment
```

## Download
Use GitHub's **Code → Download ZIP**, extract the archive, and open the assignment directory.

## Requirements
- A modern web browser.
- JavaScript enabled.
- Python 3 only if you want to run the optional validator or static server.

There is no package installation step, build step, or environment configuration.
