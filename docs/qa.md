# 🔍 Quality Assurance Guide

## Quality dimensions
- **Behavior:** conditions select the intended branch and loops terminate.
- **Clarity:** a beginner can trace the example.
- **Assets:** local teaching images resolve.
- **Documentation:** descriptions match the checked-in source.
- **Accessibility:** page structure and alternatives are reviewed.
- **Security:** no secrets or unsafe dynamic execution are introduced.

## QA workflow
1. Inspect the changed source and its learning objective.
2. Run the structural validator.
3. Open the affected page in a browser.
4. Compare Console output with the expected behavior.
5. Check local images.
6. Review documentation links and claims.
7. Record untested areas honestly.
