# 💡 Solution Overview

The assignment uses five independent HTML pages with embedded JavaScript. This keeps the examples easy to open and inspect without package installation or a server.

| Page | Teaching approach |
|---|---|
| Q1 | Hard-coded values demonstrate conditional branching and a switch |
| Q2 | A marks value demonstrates ordered grade classification |
| Q3 | Three loop forms repeat messages five times |
| Q4 | A counter and transformed output demonstrate numeric range boundaries |
| Q5 | Two while loops demonstrate ascending and descending output |

The browser executes the inline script when the page loads. Output is sent to the Developer Tools Console. The repository's current solution is deliberately simple; no application framework is required.
