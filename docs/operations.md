# 🛠️ Operations Guide

## Routine tasks
- Review issues and pull requests.
- Preserve source exercises and assets.
- Run the structural validation script.
- Verify changed pages in a browser.
- Keep documentation synchronized with code.
- Review GitHub workflow permissions and action versions.

## No service operations
There is no backend deployment, database administration, scheduled job, or on-call service to operate. Operational guidance should expand only if the repository's architecture changes.
