# 🌐 Browser and Runtime Compatibility

## Current expectation
The five HTML pages should be opened in a current mainstream browser with JavaScript enabled. The repository does not declare a formal browser support matrix or run cross-browser automation.

## Manual compatibility checks
- [ ] Current Chrome or Chromium-based browser.
- [ ] Current Firefox.
- [ ] Current Safari where available.
- [ ] Current Microsoft Edge.
- [ ] JavaScript enabled.
- [ ] Developer Tools Console available.
- [ ] Local instructional images load.

## Reporting a compatibility issue
Include browser name/version, operating system, exercise page, exact reproduction steps, and console errors. Do not claim universal browser support without testing.
