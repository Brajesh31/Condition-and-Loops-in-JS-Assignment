# 📦 Module and Page Documentation

The assignment has no ES modules or imported JavaScript packages. Each HTML page is documented as an independent learning module.

| Page | Responsibility | Important logic |
|---|---|---|
| Q1.html | Decision structures | age, temperature, day |
| Q2.html | Grade classification | ordered marks comparisons |
| Q3.html | Loop comparison | for, while, do...while |
| Q4.html | Numeric range | counter condition and `i + 1` output |
| Q5.html | Counting | `i + 1` ascending and `j - 1` descending |

When modifying a page, keep its teaching objective focused. Avoid moving examples into shared files unless a real need for reuse emerges.
